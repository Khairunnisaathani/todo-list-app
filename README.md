To-Do List App

Project Description

The To-Do List App is a simple task management application developed using HTML, CSS, and JavaScript. It helps users organize their daily activities by adding, deleting, and filtering tasks.

Internship Task

SDM Technology Internship – Week 2: DOM Manipulation and Events.

Technologies Used

- HTML5
- CSS3
- JavaScript

Features

- Add new tasks.
- Delete tasks.
- Mark tasks as completed.
- Filter all, pending, and completed tasks.
- Save tasks using Local Storage.
- Update the webpage dynamically using DOM manipulation.

Concepts Learned

- DOM Manipulation
- JavaScript Event Listeners
- Functions and Arrays
- Event Handling
- Local Storage

Project Files

- "index.html" – Website structure.
- "style.css" – Styling and design.
- "script.js" – Application functionality.

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Start adding and managing your tasks.
